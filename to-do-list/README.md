# React To-Do List

A simple and interactive **To-Do List** built with React. This application allows users to add, delete, and reorder tasks.

---

## Features

- Add new tasks
- Delete existing tasks
- Move tasks up or down in the list
- Simple and responsive UI

---

## Theory Used

- **useState**: React Hook for managing component state.  
- **Event Handling**: `onChange` for input changes, `onClick` for button actions.  
- **Array Methods**: `map` to render tasks, `filter` to delete tasks, spread operator (`...`) to copy arrays, swap technique to move tasks up/down.  
- **Conditional Rendering**: Prevent adding empty tasks and disable moving beyond first/last task.  
- **Component Structure**: Functional React component.
