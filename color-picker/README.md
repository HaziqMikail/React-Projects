# 🎨 React Color Picker

This is a simple **React Color Picker** project I built while learning from the YouTube tutorial:  
[React Tutorial for Beginners by Bro Code](https://www.youtube.com/watch?v=CgkZ7MvWUAA)

---

## 🧠 What I Learned
- How to use the **useState()** Hook in React.
- How to handle **input events** in functional components.
- How to apply **inline CSS styles dynamically**.
- How to manage component state to reflect real-time UI changes.

---

## 💡 Project Overview
This app allows users to pick a color using an HTML color input element and displays the selected color dynamically.
